# Claude Code plugins, in readable form. What declares the set is `enabledPlugins` in
# .chezmoitemplates/claude-settings.json: a plugin absent from there is disabled at the next
# `chezmoi apply` whatever this file says. This list carries what the JSON cannot, the reason a
# plugin is here and the reason another was rejected, and bootstrap.sh replays it with
# `claude plugin install <plugin>@<marketplace> --scope user -y` so the plugins are unpacked
# before the first session. Adding one means editing both, plus claude-marketplaces.txt.
#
# Only user scope is listed. The live registry also holds project- and local-scope installs
# under ~/Work: those belong to work repositories, not to this machine, and --scope user would
# not reproduce them anyway.
#
# A plugin runs unsandboxed, a marketplace listing is not a security audit, and the `-y` that
# bootstrap.sh passes waives the install-time prompt for marketplace-declared commands: read a
# plugin's hooks and commands before adding it here.
