# Omarchy shell plugins installed from git, added with: omarchy plugin add <url> --enable
# Community plugins run unsandboxed and marketplace approval is not a security audit:
# read a plugin's source before adding it here.
#
# Removable drives in the bar: mount, open and eject USB sticks, SD cards and external
# disks. Reviewed at 1.8.0: udisksctl, lsblk, busctl, gio and udevadm only, no network,
# no sudo or pkexec, no mkfs or dd. Filesystem repair goes through UDisks2 and is offered
# only after a failed check, authorised by volume UUID rather than by /dev path.
https://github.com/Wian47/omarchy-removable-drives.git
#
# Forecast: weather pill with UV, rain, sunrise and sunset. Replaces omarchy.weather in the
# bar, which shell.json disables. Reviewed at 1.3.2, commit 530df8e: curl over HTTPS to
# wttr.in and Open-Meteo as argv arrays, no file writes of its own, no sudo. With no location
# in ~/.local/state/omarchy/settings/weather.json, wttr.in geolocates the public IP on every
# refresh (15 minutes).
https://github.com/paytbidd/omarchy-weather.git
#
# Keyboard layout switcher: replaces omarchy.keyboard-layout in the bar. Reviewed at 0.1.0,
# commit 6c0da7f: reads kb_layout from `hyprctl -j devices` and switches with
# `hyprctl switchxkblayout`, so it follows us,latam from hypr/input.lua and writes no config.
# No network, no sudo. Its README suggests CTRL+ALT+SPACE; left unbound, since
# grp:alt_space_toggle already cycles and the chord would reach xkb as Alt+Space too.
https://github.com/jesusarchive/omarchy-keyboard-layout-switcher.git
#
# Nothing Control: battery, noise control and EQ for Nothing and CMF earbuds over RFCOMM.
# Reviewed at 0.1.0, commit 0cc7777: no network at runtime, no sudo, no bundled binaries.
# With no such earbuds paired it starts no process and the widget stays hidden. Upstream
# bug: `watch()` in helper/nothing_ear.py names an undefined `model`, so with the panel open
# the helper dies and reconnects every 60 seconds.
https://github.com/Pinta365/omarchy-nothing-control.git
#
# Added 2026-09-24, each read in full at the commit named. Unless an entry says otherwise:
# argv only, no network, no sudo. Any setting changed from a panel writes shell.json, so
# re-add it. Installed but disabled, off the bar until wanted with `omarchy plugin enable
# <id>`: calendar, decent-workspaces, bluetooth-audio, omaspotify, omaplug, omamail,
# agent-skills-manager, omadoro, desktop-ambience, time-machine, notification-center, webcam,
# hyprmoncfg, screen-time, qs-bitwarden-cli, omarchy-firewall, omasecurity and
# dizziee.system-updates. The bar is the one this machine had before these plugins arrived:
# omarchy.clock, local.workspaces, omarchy.bluetooth and omarchy.indicators. Spotify's tray item reports Status Passive for its whole life, and
# omarchy.tray skips every Passive item (Tray.qml:172), so pinning spotify-client shows
# nothing; a clone that let pinned Passive items through did not show it either, and was
# dropped, and spotify-client is out of the tray's pins. bootstrap.sh adds every
# URL here with --enable, so a fresh machine shows them all until they are disabled again.
#
# Omaland: Hyprland look and feel, replaces patina. Reviewed at 4428149. Writes a fenced block
# into hypr/looknfeel.lua, and into hyprland.lua for opaque windows, then `hyprctl reload`:
# both are chezmoi targets, so a change made in the panel is lost at the next apply unless
# looknfeel.lua is re-added.
https://github.com/bobby-nicholas/omaland.git
#
# Omaplug: plugin manager, replaces the plugin browser. Reviewed at 9da73fc. Installs through
# `omarchy plugin add`, so omarchy-git-url-check applies. Its update runs
# `omarchy plugin update --yes`, which skips the diff: never "Update all", update one plugin
# from a terminal. Shortcuts it offers write a block into bindings.lua; declare them there.
https://github.com/fross100/omaplug.git
#
# Decent Workspaces: per-monitor workspaces with app icons, replaces local.workspaces, whose
# source stays under dot_config/omarchy/plugins. Reviewed at 926bf52, no writes.
https://github.com/TheTrueFerret/omarchy-decent-workspaces.git
#
# Spotlight: launcher on SUPER + SHIFT + X. Reviewed at 466b704. Its first start binds
# ALT + SPACE into bindings.lua, the chord grp:alt_space_toggle owns; create_spotlight.json
# marks that tour done, so it must be applied before the plugin loads. Web suggestions off;
# currency rates reach api.frankfurter.dev.
https://github.com/maajix/omarchy-spotlight.git
#
# Zen Lock: replaces omarchy.lock. Reviewed at 989d06d: the same WlSessionLock and PAM flow as
# the stock lock, line for line. Chosen knowing its cost: Restart and Shut Down on the lock
# screen need no authentication, and as a frozen fork it gets no fix made to omarchy.lock.
https://github.com/rover-001/zen-lock.git
#
# System Updates: replaces omarchy.system-update, adds AUR, Flatpak and mise. Reviewed at
# a4cb466. Chosen knowing its cost: the Arch button runs pacman -Syu past
# omarchy-update-pacman-guard, so no snapshot and no migrations; `omarchy update` stays the
# path for a full update. The command it runs is read from its cache in ~/.cache.
https://github.com/JJDizz1L/dizziee.system-updates.git
#
# Bluetooth Audio: replaces omarchy.bluetooth. Reviewed at 4c8b079. Device names from the scan
# render as AutoText where the stock panel uses PlainText, so a nearby device can style the list.
https://github.com/ssupt/omarchy-bluetooth-audio.git
#
# Omaspotify: Spotify client, service unit omaspotify.service. Reviewed at 19b6804. The first
# load downloads its backend from GitHub releases, verified by SHA256SUMS and gh attestation,
# and falls back to cargo. It uses the stappmus/librespot fork, which was not audited, and
# keeps the playback credential in plain text under ~/.local/state/omaspotify. Its lyrics
# button installs stappmus/Omasing with --yes: do not press it before that repo is read.
https://github.com/jeremylanger/omaspotify.git
#
# Omamail: mail client. Reviewed at 3024f02; the marketplace's validated commit is not in the
# repo. It has no switch for its AI actions: they run `claude -p --permission-mode dontAsk`
# with no tool limit and untrusted mail in the prompt, only when asked from the compose or
# prompt UI, and "Suggest calendar events" stays off. Do not use them. It registered itself as
# the mailto handler in mimeapps.list, a chezmoi target.
https://github.com/huacnlee/omamail.git
#
# Hyprmoncfg: monitor profiles, installed to test. Reviewed at 1ba6b75 (rc). The daemon is
# hyprmoncfg-bin from the AUR, a prebuilt binary not audited and not installed. `manage`
# edits hyprland config chezmoi owns and conflicts with monitors.lua.tmpl: not run.
https://github.com/crmne/omarchy-hyprmoncfg.git
#
# Calendar: Google Calendar in the bar. Reviewed at 08f5c01. Needs gws and gcloud and its
# sync/setup, not run yet. That setup installs a user timer that runs the plugin's own Python
# every five minutes, so an update changes what it runs.
https://github.com/tmn73/omarchy-calendar.git
#
# Time Machine: restic backups. Reviewed at 94bc1ce. Password in a 0600 key file, passed by
# file, never argv. `omarchy-time-machine install` writes timers whose ExecStart is the script
# in the plugin directory: an update changes what the nightly timer runs.
https://github.com/jankeesvw/omarchy-time-machine.git
#
# Notification Center: keeps every notification, bodies included, in plain text under
# ~/.local/state/omarchy-notification-center, 0600, 30 days. Reviewed at e4c4568.
https://github.com/jankeesvw/omarchy-notification-center.git
#
# Screen Time: per-app usage, kept 365 days in ~/.config/omarchy/screen-time, 0644. Reviewed
# at 2c7b75a.
https://github.com/ax1g/quickshell-screentime-plugin.git

# Webcam: V4L2 controls with a preview. Reviewed at 6772b78. Its IPC `open` turns the camera on

https://github.com/kristoferlund/omarchy-webcam.git

https://github.com/klaudworks/omadoro.git

https://github.com/OldJobobo/desktop-ambience.git

https://github.com/oliwier-xiao/agent-skills-manager.git

https://github.com/tallsam/omarchy-navbar-cat.git

# Shell Settings: shell, plugin and bar settings panel. Reviewed at 2d6cdf7. Any change
# rewrites shell.json whole, and its local install copies a folder without validating it.
https://github.com/AyushKr2003/shell-settings.git
#
# Bitwarden: vault in the bar. Reviewed at ebfe90a. Needs `bw`, which comes from mise
# (`mise use -g npm:@bitwarden/cli`) because the bitwarden-cli package wants nodejs-lts-jod
# and conflicts with nodejs. rememberSession and sshAgentEnabled are false in its shell.json
# entry, and quick unlock is left unset: the SSH agent and quick unlock run two prebuilt ELFs
# whose hashes live in the same repo, so a push can swap binary and hash together. Its
# settings write the account email into shell.json; check the diff before re-adding it.
https://github.com/Elevate08/qs-bitwarden-cli.git
#
# Firewall: ufw rules from the bar. Pinned to 98a1a43, remote HEAD checked equal before the
# clone. Every change runs a fixed argv, `pkexec … /usr/bin/ufw`, through the closed grammar
# of run-action.pl, so an update to that file runs as root once polkit is answered: never
# update it from omaplug, read the diff first. It allows `disable`.
https://github.com/illegalstudio/omarchy-firewall.git
#
# Omasecurity: posture auditor, installed as a reader only; it changes nothing and copies a
# fix command to the clipboard. Reviewed at 4507720. Its verdict is not proof: a check that
# raises counts as passed with 10/10, and a plugin named omasecurity or with its code under
# tests/ passes the scan. It runs `sudo -n -l` and `sudo -n ufw status` every 15 minutes.
https://github.com/ucmz851/omasecurity.git
#
# Sudo Watch: a critical notification and a sound when a sudo or pkexec prompt waits over 20
# seconds. Pinned to eec210b, the marketplace's observed commit, checked out detached after
# the add: never update it. bin/sudo-watch.sh:19 sources ~/.config/sudo-watch/config as shell
# every cycle, so a value set with `sudo-watchctl` runs as code; the sound stays at its
# default. It watches processes only, so a polkit request over D-Bus (systemctl, udisks) is
# never flagged. The notification carries the full command line of the waiting process.
https://github.com/TaylorBurke/sudo-watch.git

# Rejected: erijl.lock, reviewed at 0a0c8d8. This machine has no /etc/pam.d/polkit-1; `enable`

# polkit. It is also a fork of omarchy.lock, which zen.lock already replaces.

# Rejected: brwsk.vigil, reviewed at 1344ebc. Its first snapshot merges a PreToolUse hook into

# screen is locked, runs `git checkout --` over paths an agent only read, and sets ~/.claude
# to 0700. Its "polkit card" is an overlay, not polkit.
